# LotKeys TEST V0.9.5.20 — grey Device chat frame and contact header

## Changes

- The expanded Device Bubble Chat uses a neutral grey outer border and header divider. Its message bubbles keep their Organization color; the compact incoming alert keeps that color as well.
- The contact phone number appears on its own line below the name in the expanded Device chat. Long names remain truncated within the available header width.

## Compatibility and test limits

This is a web-only TEST update on top of V0.9.5.19. The V0.9.5.12 Android connector, paired trust, SMS sending, Device history, last-replied Bubble Chat selection, and Hub placement are unchanged. Visual confirmation on a paired phone is still needed.
